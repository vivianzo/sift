# Keepsake

An iPhone app for going through photos after a concert or a trip. It groups photos into moments by time and place, stacks near-identical shots, and helps you keep the best one from each stack. Everything runs on device, and the app only stores references to photos in your library, never copies.

*Keepsake is a working name.*

## Status

Early. There is a clickable web prototype, and the iOS app hasn't been started yet.

- `prototype/index.html`: open it in a browser to click through the flow
- `docs/tickets.md`: starter tickets, in order
- `docs/design.md`: colors, type, and shape

## Plan

SwiftUI + PhotoKit for the photo library, Vision for grouping and scoring, SwiftData for saving picks. iOS 17+.
